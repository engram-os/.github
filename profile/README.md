  # Engram OS

  **Your AI. Your machine. Nothing leaves.**

  Engram is a local-first personal AI: it remembers what you tell it, answers
  questions grounded in those memories, and runs scheduled agents — entirely on
  your own hardware. Local Llama 3.1 via Ollama, encrypted vector memory in
  Qdrant, tamper-evident audit log. No cloud LLM, no telemetry, no call-home.

  The demo above was recorded with Wi-Fi off the whole time. That's the point.
